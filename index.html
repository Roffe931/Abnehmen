⚙️ Einstellungen & Datenschutz

🔒 Lokal auf diesem Gerät

Alle Einträge liegen im lokalen Speicher dieses Browsers. Keine Anmeldung, kein Server und keine Übertragung an uns. Bei gelöschten Website-Daten, privatem Browsen oder Gerätewechsel können Daten verloren gehen. Auf einem geteilten Gerät sind sie nicht gesondert passwortgeschützt.

Empfohlen: verschlüsseltes Backup mit einem langen Passwort. Passwort gut aufbewahren – ohne Passwort ist das Backup nicht wiederherstellbar. Unverschlüsselte JSON-Dateien enthalten sensible Gesundheitsdaten und Fotos im Klartext. Import ersetzt nach Bestätigung alle bisherigen Einträge.
